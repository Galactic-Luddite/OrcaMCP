### What's Changed

**Up to date with OrcaSlicer: 1,357 upstream commits since v2.5.0.11-dev.** Among them, in the app:
texture displacement (paint a part and bake a height-map texture into its surface), IDEX and IQEX parallel
printing (copies or mirrors on every carriage, chosen per plate), belt printers, multiple and height-aware bed
exclusion volumes, Fix All and Fix All Plates in the object list, Drop to bed, Align and Distribute, a section
view, the centre of mass, and a rewritten mesh repair on CGAL 6.2. Three bugs this project reported upstream are
fixed there and now come from upstream: small binary STLs that loaded empty (#15993), settings saved as "true"
whatever they said (#15994), and a plate's spiral vase updating only its first object (#15995).

**New and changed MCP tools** (103 in the app, 107 with the bridge's):

- **`drop_to_bed`** (new): the app's Drop. An object's lowest point goes to the bed, down or up; `instance_id`
  drops one copy, `volume_id` one part within its object. One undo step, none when it already rests there.
- **`repair_mesh`** now runs upstream's new repair: each volume is repaired in place (cracks welded, shells
  oriented, holes filled, self-intersections and tiny stray shells removed), never split into parts. The answer's
  `repair` gives what was done (holes filled, vertices welded, ...) in place of the old split / dropped counts. A
  volume from which no solid can be built is left as it is, and the answer names it.
- **`repair_mesh` Fix All**: `plate_index` repairs every object on a plate, `all_plates: true` every object in the
  project, as the plate menu's Fix All / Fix All Plates. One undo step; each object's result in `objects`; objects
  the call's wait did not reach are named in `next_steps`.
- **Bed exclusion volumes**: `get_scene_info` reports each plate's `exclusion_regions` (outline, height range, the
  extruders it applies to) and lists collision volumes in `occupancy`; `render_plate_view` draws them, a
  height-limited one at its height and, in a layer plan, dashed when not at that layer; `set_prime_tower_position`
  reports a tower that would stand in one.
- **`undo` / `redo`** are refused while an arrange, orient or other job runs, where the app's own undo now does
  nothing: they used to answer success for a step never taken.

**Flashforge** (firmware 2.0.0 and more):

- Every printer state firmware 2.0.0 reports, and the job's thumbnail.
- A send checks the slot's material and that the printer is ready before it starts a print.
- The slice table now has time points inside layers, so progress and time left move smoothly within a layer.
- `get_print_estimate` reports ironing time apart.
- `get_printer_status` says whether the flashforge-obico agent took a print's slice table.
- A print's start record is kept on disk, so a restarted OrcaMCP still reads a running print by its slice.

**Fixed**

- Slicing any painted (multi-colour) object aborted: two segmentation sources defined the same internal class
  (offered upstream as PR #16774).
- OrcaMCP refused G-code files written by OrcaSlicer itself ("Not a G-code file generated by OrcaMCP"), so
  `load_model` could not preview them.
- `printer_control` says when a command the printer did not answer may still have taken effect, rather than reporting it simply failed.
